# TJPP4-Modding
Way to keep track and download my mods for The Jackbox Party Pack 4. 

This should be COMBINED with your Party Pack 4 folder, this DOES NOT have everything included. I am making this on a Mac, your folder structure might be slightly different depending on your OS.

THIS MOD IS NOT ASSOCIATED WITH JACKBOX GAMES INC. This reposistory only includes ingame assets that have been modified, and has NO copy of the game itself. 
The files used in this repository should only be used with a legal copy of The Jackbox Party Pack 4.
